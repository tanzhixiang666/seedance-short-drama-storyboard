## 1. 镜头语言总原则：把“摄影机”当成角色、把“运动”当成动机

《电影人之眼》这几段讲得非常核心：

- **主观镜头** 经常是运动镜头，运动方式与硬件策略会一起决定“主观体验像不像”。
- **双人镜头/多人镜头** 的焦距选择会直接改变人物关系在画面里的“距离感”（远摄压缩、广角拉开）。
- **斜拍镜头** 用来制造失衡、不安与异常感，而且“少用更有效”。

把这些翻译成 Seedance 2.0 的提示词写法，就是一句话：

任何运镜都要回答：**为什么动？从谁的感受出发？动到哪里停？停下来让观众看什么？**

你如果只写“推近、摇镜、升格、电影感”，模型很可能给你一个“看起来在动，但叙事不动”的镜头；你要写的是：**动机 + 运动轨迹 + 终点信息量**。

## 2. 提示词里要写清楚的“镜头七要素”（导演口令格式）

为了让模型稳定执行“运镜”，建议每个镜头都用接近拍摄通告的写法，至少包含这七项（你可以一行一行写）：

1. **镜头类型**：主观/双人/多人/过肩/建置/跟拍/推拉/摇镜/斜拍等
2. **景别**：远景/全景/中全景/中景/中近景/特写/大特写（你书里目录这套就很好用）
3. **机位与角度**：平视/轻俯/俯拍/轻仰/仰拍；机位高度（腰平、胸平、眼平、头顶、贴地）
4. **焦距倾向**：广角/标准/中长焦/长焦（不一定要写具体 mm，但写“广角夸张纵深/长焦压缩空间”很关键）
5. **运动方式**：手持、斯坦尼康、轨道、摇臂、无人机、肩扛；以及“稳定/轻微抖动/明显奔跑抖动”
6. **运动路径与速度**：从 A 到 B，直线/弧线/环绕/前推后拉；慢—快—慢（加减速曲线）
7. **叙事目的（必须写）**：揭示关系、制造压迫、表现醉酒/眩晕、强调某个物体、把环境变成角色等

你会发现这七项基本对应你上传文本里每章的“技术因素”：镜头、格式、灯光、打破常规——Seedance 2.0 其实就是把这些“摄影决策”变成可语言化的指令。

## 3. 主观镜头（POV）运镜手册：让观众“进入身体”

### 3.1 主观镜头的三种常用运动范式（按《电影人之眼》的逻辑扩写）

**范式 A：真实步态（沉浸式）**

- 适用：走路、奔跑、穿过人群、进入狭窄空间
- 运镜要点：轻微上下起伏、呼吸感、转头时有惯性滞后
- 镜头策略（与你书一致）：想掩饰抖动用**广角**更自然；若想更“设备感”，用更稳定的轨道/斯坦尼康也可，但要解释为“角色很冷静/训练有素/像监控视角”

**范式 B：凝视聚焦（心理主观）**

- 适用：角色被某物吸引、怀疑、恐惧、爱慕
- 运镜要点：先在环境里“游移”，然后“突然定住”并慢慢推近目标
- 焦距：偏长焦可以“收窄视野”（你书里就提到用远摄收窄视野表现凝望）

**范式 C：生理异常（醉酒/药物/眩晕）**

- 适用：醉酒、缺氧、恐慌发作、药物幻觉
- 运镜要点：轻微旋转、漂移、焦点不稳、暗角、重影/叠化感（你书里举了鱼眼、叠化的“屡试不爽”手法）
- 注意：要写清楚“异常程度”，因为大角度倾斜或过强变形会损害可看性（这点与斜拍章节的提醒一致）

### 3.2 主观镜头提示词模板（可直接粘贴改）

```markdown
镜头1｜主观POV｜中景→中近景
机位：眼平，角色视线高度；角度平视
镜头：广角视野，夸张纵深但不畸变过度
运镜：手持行走，轻微呼吸起伏；转头有惯性滞后
路径：从走廊入口前进3米→右转→停在门口
速度：慢→略快→在门口减速停住
叙事目的：让观众感到“我正在走近危险”，最后停住让门缝成为信息点
画面要点：门缝透出冷光，走廊尽头有模糊人影
光线：室内低照度，允许道具灯入画（台灯/门缝光）
```

你也可以把“异常主观”改成：

```markdown
镜头｜主观POV｜中近景
运镜：轻微旋转漂移，像醉酒；边缘暗角；偶尔短暂失焦再拉回
叙事目的：传达眩晕和不可靠感，但仍能看清对方嘴型与关键动作
```

## 4. 双人镜头（Two-shot）运镜手册：用“距离感”讲关系

你上传的文本里双人镜头的核心不是“画面里有两个人”，而是：

- 它常作为对话主镜头（master shot）
- **调度与构图让观众对比、审视两人关系**
- 焦距会改变“亲密/对抗”的空间感：长焦压缩让两人更近，广角拉开让隔阂更强
- 当你不切特写、只用双人镜头，观众会更主动去挖掘戏剧张力（巴赞“场面调度美学”那段）

把这转成运镜，就是：**不要靠切镜头推进戏，而靠人物调度与镜头内运动推进戏**。

### 4.1 双人镜头四种“导演级用法”

**用法 1：静中有动（不剪辑的张力）**

- 镜头不动或极轻微漂移
- 让人物在画面里通过走位改变关系：靠近、背对、错开视线、交换前后景位置
- 提示词里要写“谁走一步、谁退半步”，否则模型只会给你“站桩对话”

**用法 2：微推近（关系升温/压迫增强）**

- 两人争吵升级时，摄影机慢慢前推
- 推到某个节点停住，让观众“被迫更近”
- 适合你想在 15 秒内完成“从客套到爆发”的情绪弧线

**用法 3：侧向环绕（权力翻转）**

- 摄影机沿弧线绕半圈
- 绕完后让原本弱势的人处于更大的画面占比或更靠近镜头（对应希氏构图法的“谁更大谁更强”那段）

**用法 4：背景叙事（环境与人物同等重要）**

- 用大景深，让环境信息清楚
- 运动幅度更克制，避免观众丢掉背景线索
- 对应《末路狂花》那种“环境象征叙事”的思路：沙漠不仅是背景，也是主题符号

### 4.2 双人镜头提示词模板

```markdown
镜头｜双人镜头 two-shot｜中景
机位：胸平，轻微上仰2-3度（强化两人决断但不夸张）
构图：两人站在三分法兴趣点，留足视线空间；开放式构图
焦距：中长焦轻微压缩空间，让两人看上去更“绑在一起”
运镜：轨道缓慢前推，几乎不可察觉
路径：从2.5米推到1.8米，停住
叙事目的：不剪辑，让观众被迫盯住两人同框的肢体语言变化
表演调度：A说完一句向前半步；B不退，抬头直视；两人气场对抗升级
灯光：人物略亮于背景一档，但背景仍可辨，强调“环境压力”也在场
```

## 5. 多人镜头（Group shot）运镜手册：先把空间讲明白，再把冲突推出来

你上传的多人镜头部分强调三点：

1. 多人镜头通常中景/中全景/全景，因为要容纳多人
2. 通过站位、面朝方向、画面占比、以及 z 轴站位建立冲突与纵深
3. 大视野让它能成为“标志性画面”，尤其在关键时刻把主题亮出来（比如《上帝之城》的“讽刺集体照式构图”）

### 5.1 多人镜头最稳的运镜策略（实操优先）

**策略 A：建置 → 轻微推进 → 定格信息**

- 先给全景/中全景，说明谁在什么位置
- 然后非常轻的推进或横移，把观众注意力“锁”到焦点人物
- 最后定住 1-2 秒，让观众读清楚站位关系（很多 AI 视频“读不清”就是因为一直动）

**策略 B：横移揭示（从遮挡到暴露）**

- 前景有人/物遮挡，摄影机侧移一点点，把关键人物/武器/表情“滑出来”
- 很适合你书里《放·逐》那种“前景对背景、明对暗”的冲突构图

**策略 C：纵深调度（z 轴是多人镜头的命）**

- 提示词明确：前景谁，中景谁，背景谁；谁在亮处，谁在暗处
- 广角更利于夸张纵深；长焦更利于把人“压在一起”形成压迫

### 5.2 多人镜头提示词模板

```markdown
镜头｜多人镜头 group shot｜中全景
构图：人物沿x轴展开像“集体合影”，但站姿带挑衅；焦点人物在画面中部略偏右
焦距：广角，强调纵深与空间压迫
运镜：缓慢横移（dolly left），从门框遮挡开始→滑出全体
光线：低调照明，背景亮处形成轮廓剪影；暗处点状光源分层
叙事目的：用同框站位展示“他们主宰这个空间”，环境成为权力象征
节奏：横移结束后停住2秒，给观众读站位与武器信息
```

## 6. 斜拍镜头（Dutch angle）运镜手册：用“失衡”表现失控，但要克制

你上传的斜拍章节给了非常明确的使用边界：

- 用于紧张、不安、困惑、抓狂、药物迷幻、环境异常
- 倾斜程度对应异常程度；接近 45° 只在极端情况
- 因为太显眼，**一场戏里少用**更有效；或轻微倾斜贯穿整场戏（但角度不要大）

### 6.1 斜拍 + 运镜的三种“高命中”组合

**组合 1：轻斜 + 缓慢推近（压迫）**

- 角度 5°-10° 足够，让观众隐约不舒服
- 推近让不舒服升级，但观众不至于出戏

**组合 2：轻斜 + 横摇（信息不可信）**

- 在对话里横摇去看另一个人时，保持倾斜角度
- 暗示“对话表面正常，底层不正常”

**组合 3：大斜 + 短时（极端瞬间）**

- 只用 1-2 秒，作为心理崩塌/突发事件的视觉尖叫
- 用完立刻回到正常机位，形成对比

### 6.2 斜拍提示词模板

```markdown
镜头｜斜拍 canted shot｜中近景
角度：向右倾斜8度（轻微失衡，不影响观看）
运镜：缓慢推近 + 极轻微手持漂移
叙事目的：对话看似平静，但观众潜意识感到“哪里不对”
光线：略偏硬的侧光制造阴影张力；背景垂直线条强化倾斜感
```

## 7. 推拉、摇镜、跟拍：把“运动”写成可执行的路径（避免模型乱漂）

Seedance 2.0 的优势在于运动与交互更强，但你仍要避免一个常见坑：**你只写“推近/摇镜”，没写“推到哪里停、摇到谁身上停、停多久”**，模型就容易给出“漂移式无目的运动”。

### 7.1 推镜（dolly in）与变焦推近（zoom in）的导演区分写法

- **推镜**：空间透视会变化，前景背景关系会产生真实位移
  - 适合：走近真相、压迫感增强、情绪逼近
- **变焦**：透视不变，只是视野收窄
  - 适合：突然注意到细节、窥视感、纪录/新闻式“抓到”感

提示词里可以这样写区分：

```markdown
运镜：真实推镜（dolly in），不要变焦
```

或

```markdown
运镜：只做光学变焦推近（zoom in），摄影机位置不移动
```

### 7.2 摇镜（pan/tilt）写法：必须写“起点—终点—停顿”

```markdown
运镜：水平摇镜 pan，从左侧空椅子开始→摇到右侧人物脸上→停住1秒
速度：先慢后快再慢（S形速度曲线）
叙事目的：从“缺席”摇到“责任人”，完成因果指认
```

### 7.3 跟拍（follow）写法：明确“跟随主体”与“镜头距离”

```markdown
运镜：斯坦尼康跟拍，镜头始终跟随A（不跟随B）
镜头距离：始终保持A胸口到镜头约1.2米
路径：穿过狭窄走廊→推门进入房间→绕过桌子停下
叙事目的：让观众像保镖一样贴身跟随，制造紧迫与代入
```

## 8. “镜头 + 光线”要一起写：运动镜头最怕穿帮与曝光崩

你上传的主观镜头“灯光”段落非常实用：摄影机运动会限制布光位置，室内夜戏甚至常规灯具都难用，建议用**道具灯**并通过调光控制；室内日戏可把大灯放窗外做“阳光”，让摄影机更自由。

把它转成 AI 提示词，就是：**你要告诉模型光源来自哪里、哪些灯具会入画、以及你允许的曝光风格**。

给你三种“稳定出片”的写法：

1. **道具灯入画**（夜戏运动最稳）

```markdown
灯光：主要由画面内的台灯/走廊壁灯提供（道具灯入画），整体低照度但人物面部可读
```

2. **窗外大面光**（室内日戏跟拍更稳）

```markdown
灯光：窗外柔和大面光像阴天自然光，房间整体均匀但人物略亮
```

3. **强对比低调**（多人镜头悬念）

```markdown
灯光：低调照明，暗部保留层次；背景亮处形成剪影轮廓，点状光源分层
```

## 9. 多镜头（15 秒）怎么写：把它当“短分镜脚本”，不要当一段散文

官方博客提到 Seedance 2.0 支持 **15 秒高质量多镜头音视频输出**。多镜头输出最关键的问题是：**镜头之间要有剪辑逻辑**，否则会出现“每个镜头都很酷，但连不起来”。

### 9.1 多镜头最稳的三段式（15 秒经典结构）

- **镜头 1（3-5s）建置**：空间关系、人物位置、环境压力
- **镜头 2（4-6s）推进冲突**：双人/多人关系变化，用推近/横移/跟拍
- **镜头 3（3-5s）落点信息**：特写/主观凝视/关键物体揭示（停住给观众读）

### 9.2 多镜头提示词模板（可直接改成你的剧情）

```markdown
生成一个15秒多镜头片段，电影叙事清晰，镜头之间有剪辑逻辑（建置→冲突升级→信息落点）

镜头1（4秒）｜多人镜头｜中全景
地点：狭小室内，门口有强背光
构图：前景3人剪影，中景2人持枪，背景焦点人物站在最亮处
运镜：缓慢横移从门框遮挡滑出全体，结束后停住1秒
叙事目的：交代空间关系与对峙阵营

镜头2（6秒）｜双人镜头｜中景
人物：A与B同框对话，气氛升级
焦距：中长焦轻微压缩空间
运镜：轨道缓慢前推，A说完向前半步，B不退
叙事目的：用同框压迫感表现关系逼近临界点

镜头3（5秒）｜主观POV｜中近景
视角：A的主观视角凝视B手里的引爆器
运镜：轻微手持呼吸起伏，缓慢推近引爆器，最后停住1秒
叙事目的：把观众注意力钉死在“关键物体”，形成悬念
```

## 10. “打破常规”专区：用少量非常规手法制造记忆点（但要写清楚理由）

你上传的文本里有两个特别好的“打破常规”案例逻辑：

- 《傀僵人生》在主观镜头上加暗角，并让观众同时听到两个人的声音，变成“有意识的主观体验”，不是简单 POV。
- 《德克萨斯的巴黎》用单向玻璃把两人影像融合，双人镜头变成“关系与错觉”的视觉隐喻。

Seedance 2.0 里你也能这么玩，但依然要遵守一个原则：**非常规手法必须服务叙事信息**。给你三种“安全但高级”的非常规写法：

1. **暗角 + 呼吸声**（意识主观）

```markdown
主观镜头带轻微暗角与边缘模糊，观众能听到角色急促呼吸；画面不是单纯视角，而是“情绪主观”
```

2. **镜面/玻璃叠影**（关系隐喻）

```markdown
通过单向玻璃反射，让A的倒影与B的脸重叠；镜头保持克制移动，强调“想回到过去只是错觉”
```

3. **轻微倾斜贯穿一场戏**（持续不安）

```markdown
整场对话都保持右倾5度的轻斜拍，观众不易察觉但持续不安；只在高潮瞬间恢复水平形成反差
```

## 11. 常见失败原因与“补救口令”（非常实用）

### 11.1 失败：镜头一直在动，观众读不到信息

**补救**：写“停住”与“停顿秒数”

```markdown
运镜结束后停住2秒，给观众读清人物站位/关键物体
```

### 11.2 失败：手持抖得像事故现场

**补救**：写清“抖动强度”与“广角掩饰抖动”

```markdown
手持但仅轻微抖动（像呼吸），使用广角以自然掩饰抖动，不要剧烈晃动
```

### 11.3 失败：推近推不到点上，焦点漂移

**补救**：写“推到哪一个物体/身体部位停”

```markdown
推近终点：停在B的右手指尖与引爆器按钮占画面中心的位置
```

### 11.4 失败：双人镜头没有关系感，就是两个人站着

**补救**：写“走位/身体朝向/遮挡关系”

```markdown
A略靠前占画面更大，B在后方半步；A的肩膀部分遮挡B，形成控制关系
```

### 11.5 失败：多人镜头像“合影”，没有戏剧冲突

**补救**：写“冲突对比对”（前景/背景、明/暗、藏/露、大/小）

```markdown
构图对比：前景暗处持枪者半遮挡，背景亮处医生暴露在光下成为焦点；明暗与遮挡制造悬念
```

## 12. 一页式速查：镜头目的 → 最适合的运镜

- **交代空间与阵营**：建置全景 + 缓慢横移/轻推进 + 停住读信息
- **表现亲密**：中长焦双人镜头 + 轻推近（距离被压缩，关系更黏）
- **表现疏离**：广角双人镜头 + 人物在画面两端 + 空间拉开
- **表现压迫**：低机位轻仰 + 推近 + 人物占画面越来越大
- **表现慌乱/失控**：轻斜拍 + 手持 + 速度变化（但角度别太大）
- **表现凝视/执念**：长焦收窄视野 + 推近到目标 + 停住
- **表现醉酒/药物**：轻旋转漂移 + 暗角/边缘模糊 + 短暂失焦回焦
