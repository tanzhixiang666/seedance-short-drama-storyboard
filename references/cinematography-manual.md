# Seedance 2.0 镜头与运镜使用手册

> 生成 video_prompt 时必须读取本手册，以世界顶级导演的水准设计镜头与运镜。

## 1. 镜头语言总原则

把"摄影机"当成角色、把"运动"当成动机。

任何运镜都要回答四个问题：
- **为什么动？**
- **从谁的感受出发？**
- **动到哪里停？**
- **停下来让观众看什么？**

只写"推近、摇镜、升格、电影感"会得到"看起来在动但叙事不动"的镜头。必须写：**动机 + 运动轨迹 + 终点信息量**。

## 2. 镜头七要素（每个镜头必须写全）

1. **镜头类型**：主观/双人/多人/过肩/建置/跟拍/推拉/摇镜/斜拍
2. **景别**：远景/全景/中全景/中景/中近景/特写/大特写
3. **机位与角度**：平视/轻俯/俯拍/轻仰/仰拍；高度（腰平/胸平/眼平/头顶/贴地）
4. **焦距倾向**：广角夸张纵深 / 标准 / 中长焦压缩空间 / 长焦收窄视野
5. **运动方式**：手持/斯坦尼康/轨道/摇臂/无人机/肩扛；稳定度描述
6. **运动路径与速度**：从A到B，直线/弧线/环绕/前推后拉；慢—快—慢加减速曲线
7. **叙事目的（必须写）**：揭示关系、制造压迫、表现眩晕、强调物体、环境象征等

## 3. 主观镜头（POV）三种范式

### 范式 A：真实步态（沉浸式）
- 适用：走路、奔跑、穿过人群、进入狭窄空间
- 要点：轻微上下起伏、呼吸感、转头有惯性滞后
- 策略：用广角掩饰抖动；若要稳定感则用斯坦尼康并解释为"角色冷静/训练有素"

### 范式 B：凝视聚焦（心理主观）
- 适用：被某物吸引、怀疑、恐惧、爱慕
- 要点：先在环境里游移，然后突然定住并慢慢推近目标
- 焦距：偏长焦收窄视野表现凝望

### 范式 C：生理异常（醉酒/眩晕）
- 适用：醉酒、缺氧、恐慌发作、药物幻觉
- 要点：轻微旋转、漂移、焦点不稳、暗角、重影叠化
- 注意：写清楚异常程度，大角度倾斜会损害可看性

## 4. 双人镜头：用距离感讲关系

核心不是"画面里有两个人"，而是调度与构图让观众对比审视两人关系。

**四种导演级用法：**

1. **静中有动**：镜头不动或极轻微漂移，靠人物走位改变关系（靠近/背对/错开视线）。必须写"谁走一步、谁退半步"，否则是站桩对话。
2. **微推近**：争吵升级时摄影机慢慢前推，推到节点停住，15秒内完成"客套到爆发"的情绪弧线。
3. **侧向环绕**：沿弧线绕半圈，绕完后让弱势方占更大画面（权力翻转）。
4. **背景叙事**：大景深，环境信息清楚，运动幅度克制，环境成为主题符号。

**焦距与关系：**
- 长焦压缩 → 两人更近、更"绑在一起"、亲密/对抗
- 广角拉开 → 隔阂更强、空间疏离

## 5. 多人镜头：先讲明白空间，再推出冲突

**三种最稳策略：**

1. **建置→轻推→定格**：先全景交代位置，再轻推锁焦点人物，最后定住1-2秒让观众读站位。
2. **横移揭示**：前景遮挡，侧移滑出关键人物/武器/表情（从遮挡到暴露）。
3. **纵深调度**：明确前景谁、中景谁、背景谁；谁在亮处、谁在暗处。广角夸张纵深，长焦把人压成压迫感。

## 6. 斜拍（Dutch Angle）：用失衡表现失控，必须克制

- 用于：紧张、不安、困惑、抓狂、迷幻、环境异常
- 倾斜程度 = 异常程度；接近45°只在极端瞬间用
- **一场戏里少用更有效**

**三种高命中组合：**
1. 轻斜(5°-10°) + 缓慢推近 → 压迫升级但不出戏
2. 轻斜 + 横摇 → 暗示对话表面正常、底层不正常
3. 大斜 + 1-2秒短闪 → 心理崩塌瞬间，用完立刻回正常机位

## 7. 推拉/摇镜/跟拍：必须写清起止与停顿

### 推镜 vs 变焦
- **推镜(dolly in)**：空间透视变化，前景背景真实位移。适合走近真相、压迫感增强。
- **变焦(zoom in)**：透视不变，只收窄视野。适合突然注意细节、窥视感、新闻式"抓到"感。

### 摇镜
必须写"起点—终点—停顿"：
> 水平摇镜，从左侧空椅子→摇到右侧人物脸上→停住1秒
> 速度：先慢后快再慢（S形速度曲线）

### 跟拍
明确跟随主体与镜头距离：
> 斯坦尼康跟拍，始终跟随A，保持胸口到镜头约1.2米
> 路径：穿过走廊→推门进房→绕过桌子停下

## 8. 镜头+光线一起写

三种稳定出片的布光写法：
1. **道具灯入画**（夜戏运动最稳）：台灯/壁灯提供光源，低照度但面部可读
2. **窗外大面光**（室内日戏跟拍）：窗外柔和像阴天自然光，整体均匀人物略亮
3. **强对比低调**（多人悬念）：暗部保留层次，背景亮处形成剪影，点状光源分层

## 9. 15秒多镜头三段式结构

- **镜头1（3-5s）建置**：空间关系、人物位置、环境压力
- **镜头2（4-6s）推进冲突**：双人/多人关系变化，推近/横移/跟拍
- **镜头3（3-5s）落点信息**：特写/主观凝视/关键物体揭示，停住给观众读

## 10. 常见失败与补救口令

| 失败现象 | 补救写法 |
|----------|----------|
| 镜头一直在动，读不到信息 | 写"运镜结束后停住2秒，给观众读清站位/物体" |
| 手持抖得像事故 | "仅轻微抖动像呼吸，用广角自然掩饰，不要剧烈晃动" |
| 推近推不到点、焦点漂移 | "推近终点：停在B的右手指尖与按钮占画面中心" |
| 双人镜头没有关系感 | "A略靠前占画面更大，B后方半步；A肩遮挡B，形成控制关系" |
| 多人镜头像合影无冲突 | "前景暗处持枪者半遮挡，背景亮处医生暴露；明暗遮挡制造悬念" |

## 11. 速查：镜头目的 → 运镜选择

| 想要的效果 | 推荐运镜 |
|------------|----------|
| 交代空间与阵营 | 建置全景 + 缓慢横移/轻推 + 停住读信息 |
| 表现亲密 | 中长焦双人 + 轻推近（距离压缩，关系更黏） |
| 表现疏离 | 广角双人 + 人物两端 + 空间拉开 |
| 表现压迫 | 低机位轻仰 + 推近 + 人物占画面越来越大 |
| 表现慌乱/失控 | 轻斜拍 + 手持 + 速度变化（角度别太大） |
| 表现凝视/执念 | 长焦收窄视野 + 推近到目标 + 停住 |
| 表现醉酒/药物 | 轻旋转漂移 + 暗角边缘模糊 + 短暂失焦回焦 |
