# Camera-Content 剧本改编格式规范

> 输入小说/剧本后，第一步先按本规范改编为 camera-content JSON 格式，再进入 Seedance 分镜提示词生成。

## 核心任务

梳理小说的故事主线，将小说改编为具有画面冲击、故事带入感的短剧剧本。

## 输出结构：分镜剧本 camera-content

包含视频提示词 + 台词 + 特效音频描述。

**视频提示词构成**：场景（地点）+ 时长 + 镜头 + 运镜 + 画面描述
**对话规则**：对话前必须是说话人名，语气放置于对话后，原文对话禁止删减、修改
**音频构成**：时长、声音描述
**时长限制**：每段 camera-content 最长 15 秒

## camera-content 写法示例

```
场景：火车车厢内

▲0~2秒:中景，肩上镜头李明身体前倾，李明:"三叔，那到底是什么东西?咋用手机还不行呢?"(急切)
▲2~4秒:特写，水平镜头，李明眉头紧锁，眼神中充满疑惑和探究。
▲4~6秒:中景，切角镜头，三叔没有回答，而是转头望向窗外，窗外是荒凉的野外，他的侧脸线条紧绷。
▲6~8秒:特写，透视镜头，三叔的倒影映在车窗上，他的表情凝重，眼神中流露出深深的忧虑。
▲8~15秒:广角镜头，低角度镜头，车厢内光线昏暗，三叔沉默不语，李明的脸上的疑惑更深了，两人之间的气氛变得更加凝重

音频：0～15秒:火车行驶的单调轰鸣声，车厢内一片寂静。
```

## 输出要求

1. 视频提示词在适当时机需要换一种描述方式，禁止出现色情、血腥、暴力、种族歧视等负面内容描述。
2. 每段 camera-content 长度节奏为 15 秒。
3. 根据剧情，每段 camera-content 的镜头需为 2-5 个。
4. 每个 `▲` 代表一个镜头的起始。
5. **输出单行、无换行符的 JSON 格式内容**，禁止输出 ```json 代码块标识符。

## JSON 输出格式

```json
{"subtitle":[{"id":1,"camera-content":"分镜1的描述","originalText":"分镜1对应的原文"},{"id":2,"camera-content":"分镜2的描述","originalText":"分镜2对应的原文"}]}
```

## 字段说明

| 字段 | 说明 |
|------|------|
| `id` | 分镜组序号，从 1 递增 |
| `camera-content` | 该分镜组的完整剧本内容（场景 + ▲时间戳镜头描述 + 音频行） |
| `originalText` | 该分镜组对应的原文片段，**禁止修改**，用于核对改写是否合理 |

## 其他约束

- 仅输出结果，不输出思考过程、不输出原因
- 原文对话禁止删减、修改
- 分镜切分点要自然，对应故事的节奏节点
