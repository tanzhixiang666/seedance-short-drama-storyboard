# Seedance 短剧分镜提示词完整规则模板

> 本文件是生成 video_prompt 时必须严格遵循的完整规范。生成前完整阅读。

## 输入信息占位

- **前一个分镜：** 前一个分镜内容作为当前分镜的前序内容，保持故事进展的顺序逻辑，是当前分镜的铺垫。第一个分镜则留空。
- **后一个分镜：** 后一个分镜内容作为当前分镜的后续内容，当前分镜的故事进展要与后一个分镜连贯顺畅，保证故事完整。

## 输入文案规则

输入文案是动态画面和台词的唯一来源，视频提示词来自于输入文案动态画面的演绎描述。对于输入文案（小说原文），应该像一个个连贯的画面一样组织成提示词语言表达出来，并且需要有绝对的连贯性。

**video_prompt 需严格限定在【输入文案】的信息范围之内，绝不进行任何超出原文的联想或创造。**

把【输入文案】作为唯一信息来源，忠实地将其内容转化为分镜脚本，避免添加任何文案中未提及的情节、动作、场景或角色心理活动。

## 生成规则（必须严格遵守）

1. **内容来源**：生成的所有内容必须严格基于【当前分镜的核心文案】。绝不允许虚构、联想或添加文案中未提及的任何情节、动作、场景或角色心理。
2. **保持连续性**：必须参考【前一个分镜】和【后一个分镜】的信息，确保新分镜的起始画面状态与前一镜的结束画面状态无缝衔接，同时为后一镜的画面开始做好铺垫。
3. **提示词分工**：
   - **video_prompt**：描述从分镜开始到结束的**连续画面**或准确的故事感语言。此部分必须使用特殊映射代码。视频提示词总字数禁止多于 900 个字，严格控制字数。

## 转换要求

### 1. 目标

把【输入文案】改写成一段"15 秒分镜组镜头"结构的标准短剧分镜剧本，节奏快、信息清晰、可直接拍摄。

如果片段没有对白和明确的表达内容，不加入对白、内心 OS，只呈现动态的镜头片段和环境音。

### 2. 明确"15 秒分镜组"

**分镜组定义（强制）：**
- 每组目标时长：13–15 秒（允许浮动，但不超过 15 秒，根据对白节奏，最好为 15 秒）
- 每组包含：3–8 个镜头（短视频最稳）
- 单镜头时长：1–4 秒
- 每组必须有一个"目的标签"：推进信息 / 制造冲突 / 情绪加压 / 反转钩子 / 交代行动

**对白约束（强制）：**
- 每个分镜组对白低于 3 句（句 = 一行台词）
- 单句尽量 ≤10 个字（短剧口播节奏更像"打点"）
- 如果信息太多：用道具特写 / 手机屏 / 动作替代解释

### 3. 视角/镜头默认决策

心理描写改成：表情、动作、停顿、回避视线、吞咽、手抖、道具互动。
避免比喻修辞，写观众能看到的画面。
不写"他想 / 她觉得 / 他意识到"等。

**默认镜头语法（每个镜头至少写清楚）：**
- 景别：中景 / 近景 / 特写 / 大特写
- 机位：平视 / 俯拍 / 仰拍 / 过肩 / 侧逆光 / 门缝窥视等
- 运动：动作点切 / 甩镜 / 撞镜 / 擦过遮挡 / 快速拉焦 / 变焦抽拉 / 贴身跟拍 / 并行侧移 / 甩跟 / 过肩快速切入 / 急停 / 快速弧线绕 / 快速推拉配合 / 俯仰甩落 / 手持抖动
- 主客观：客观 / 主观 / 半主观（需要时才用主观）

**自动选镜头的"条件句"（硬规则）：**
- 对白对峙：默认过肩（OTS）+ 反打，中景为主，关键字落在特写，对白有对象感表达
- 情绪变化：切反应特写（眼神 / 手 / 呼吸 / 吞咽）
- 信息关键物：给道具特写（支票、日记本、手机屏）
- 压迫 / 强弱关系：强者略俯拍弱者，或弱者仰拍强者
- 钩子结尾：最后 1 镜头尽量是特写 / 大特写（表情或关键物）卡点结束

**快速运镜的商业标准参数 / 控制点：**
- 镜头时长：0.3–1.2s 为主，爆点特写常在 0.3–0.6s
- 运动曲线：起势快 → 中段最快 → 末端急停（最关键）
- 模糊管理：模糊只用于过渡，中间可以糊，但落点必须清
- 切点位置：优先切在动作峰值（拔剑 / 出拳 / 回头那一下）、声音峰值（剑鸣、脚步重拍、呼吸吸气）、急停那帧（最有"爽感"）
- 快门观感：动作类常偏小快门角（更脆更硬），注意闪烁与光源频闪
- 稳定策略：快不等于晃。商业片常用"稳底盘 + 动作点轻震"的组合

### 4. 短剧分镜模板

**镜头最小单位：必须回答 6 个问题（缺一不算镜头）：**
1. 对准谁：角色 / 道具 / 环境
2. 对准哪里：头部 / 眼睛 / 嘴角 / 手指 / 胸口 / 脚 / 背影 / 肩线 / 下巴 / 喉结 / 手机屏 / 信封封口…
3. 表情是什么：皱眉 / 抿嘴 / 眼神躲闪 / 瞳孔放大 / 强笑 / 咬牙 / 呼吸急促 / 眼眶发红…
4. 在做什么动作：捏紧杯壁 / 指尖颤 / 吞咽 / 后退半步 / 手停在半空 / 攥住衣角 / 把东西拍桌上…
5. 连续片段：用一个事情动作，多个连续片段串联，保证故事连贯完整，避免硬切场景的割裂感
6. 片段信息点：片段里必须看到的关键物 / 关系（支票压住桌布纹路、日记本标题、两人距离、门缝、监控红点）
7. 镜头位置与运动：平视 / 俯 / 仰 / 过肩 / 侧后方 / 门缝窥视；固定 / 轻推 / 轻移 / 手持微抖

**部位库（直接套）：**
- 情绪：眼睛 / 瞳孔 / 眼眶泪光 / 嘴角抽动 / 下颌线绷紧 / 喉结上下动
- 紧张：手指扣紧 / 指节发白 / 攥衣角 / 脚尖后撤 / 鞋跟轻挪
- 压迫：手掐下巴 / 手按墙 / 领口被拽 / 身体前倾的肩线
- 证据：手机屏（聊天 / 转账 / 定位）/ 支票数字 / 日记本标题 / 指纹 / 钥匙 / 录音红点
- 反转钩子：大特写停在"眼睛骤缩"或"道具关键字"上

**默认选镜头硬规则（避免乱切）：**
- 对白：先拍说话者的嘴 + 眼（近景），再切听者的眼神反应（特写）
- 情绪升级：不换场景，直接从中景跳到眼睛 / 手特写
- 冲突动作：先给手（动作主体），再给脸（后果反应）
- 片段连接：一个人物的表达用多个片段切片段方式，形成连贯观看体验，增强信息暗示
- 信息揭示：先给道具特写，再给角色表情特写
- 15 秒一组：最后一镜头必须是**大特写（眼 / 道具关键字）**卡点

### 5. 根据情感重心分配特写

- 关键台词给说话者特写
- 反应比台词重要时，给听者特写

### 6. 空间关系与运镜

- 新场景与后续场景保持空间一致
- 人物移动时考虑跟踪镜头
- 运镜方式要描述：
  - 景别：仅限中 / 近 / 特写
  - 机位与高度：机位位置、机身高度（腰平 / 胸平 / 眼平 / 俯 / 仰）、水平角度（正侧 / 45°）
  - 镜头参数：焦段（24 / 35 / 50 / 85mm 等）、光圈 / 景深意图（浅景深锁眼神 / 深景深交代空间）
  - 运动方式：推 / 拉 / 摇 / 移 / 跟 / 升降 / 绕 / 甩 / 手持 / 斯坦尼康 / 轨道 / 摇臂 / 无人机
  - 运动路径与幅度：从哪到哪、移动距离 / 弧线半径 / 绕行角度（例如"绕人物 120°"）
  - 速度与节奏：慢推 / 匀速 / 加速 / 急停 / 呼吸感（可以写"2 秒到位""缓入缓出"）
  - 对焦与主体切换：跟焦目标、焦点转移（A→B）、何时拉焦
  - 构图变化：从三分构图到居中、从遮挡到开阔、前景 / 框中框
  - 动作点与落点：镜头跟随什么动作开始，落在哪个信息点结束

### 7. 蒙太奇衔接

创作不同画面之间内容连贯的细节片段。每个画面、每个分镜的切换是有连续性的，通过镜头片段之间衔接构建叙事连贯性与情感张力。符合人的行为逻辑、心理逻辑和强化感受升级的逻辑。

**经典蒙太奇示例**：第一个镜头是一个男人的中景，表情平淡，深深看着前方远处；第二个镜头是一片暗流涌动的海水。观众看完后完成自我心理暗示："这个男人在看海"——这就是最基本的镜头语言和蒙太奇。

### 8. 分镜分隔与时长

每一个分镜独立给一个空一行的分隔符，使分镜自动切分。分镜要求不超过 10 秒核心内容，保证片段分镜频率不枯燥（如果是对白，一般不超过四句）。

### 9. 构图与场景

每个片段都是一幅有意图的构图，不随便，场景描述要详尽，片段表达详细清楚。

### 10. 场景边界识别

地点变化或时间跳跃时，新起一场。

### 11. 删除无法拍摄的内容

- 内心独白转化为表情、动作或台词
- 叙述者评论转化为视觉呈现
- "他想""她觉得"等心理描写，用行为外化

### 12. 用影视语言重写描述

- 避免文学修辞，写观众能看到的画面
- 动作要具体、可执行
- 声音要单独标注

### 13. 清晰明了

与其用"一条美丽的街道"这样模糊的描述，不如写成"湿漉漉的沥青路面、斑马线、霓虹灯的倒影"。与其说"快速移动"，不如具体说明"慢跑三步，在路边停下"。使用指向可见结果的动词和名词。

### 14. 细节连贯

注意人物的时间、天气、服装、语气、角色外貌和年龄、拍摄角度、剪辑有几个片段、场景设计以及其他许多因素，都要有所提及，但上下要有衔接。

### 15. 流畅运动

通过为每个镜头定义一个摄像机运动和一个拍摄对象动作，实现流畅、可预测的运动效果。

### 16. 对话模块

将简短的对话放在专门的"对话"模块中，以确保口型同步和逐字逐句的演绎最为精准。

### 17. 多镜头序列

在创建多镜头序列时，将每个镜头定义为一个独立的模块，每个模块都有其独特的设置、动作和光线，以保持最大的控制力。

### 18. 角色声音描述

**每个角色只能使用一个声线，OS 必须是同一个声线。**

**A. 声线要求（固定，不随剧情变）**
写"这个人天生的声音指纹"，只允许在强弱、快慢、气息上调，不允许换音色或人设音。必须包含：
- 性别 / 年龄段 / 音域倾向（偏低 / 中 / 偏高）
- 音色关键词（清冷 / 温润 / 沙哑 / 金属感 / 少年感…）
- 咬字与节奏（字头重不重、字尾收不收、语速基准）
- 气息与共鸣（胸腔 / 鼻腔、稳不稳、换气习惯）
- 口音 / 语体（古风 / 现代 / 方言倾向）
- 角色人设感

对白声线类型参考：奶狗 / 软萌男友音、病娇 / 阴郁疯批音、仙气空灵音、古风公子 / 侠客音、可爱萌音、冷酷御姐、冷酷霸总、女强角色音、温柔大哥哥音、甜冷病娇音、话唠快嘴吐槽音、冷静理工分析音、寡言冷面音、懒散嘲讽大神音、硬汉铁血队长音、猥琐流老狐狸音、傲慢天才狂气音、成熟温柔女神音、绿茶甜心 / 撒娇小狐狸音、清冷禁欲刑警音、憨憨少爷音、巨星舞台磁性音、混血贵公子疏离音、市井暖男大叔音、破碎感低语坚韧音

**禁止项**：不能突然奶音、不能突然磁性大叔音、不能突然甜妹，解说和角色固定。

**B. 现在状态的语气特点（可变，随剧情变，≤10 字）**
写"这句话怎么说"——同一声线上的表达旋钮：
- 音量：低 / 中 / 高（或 1–5）
- 语速：慢 / 中 / 快（或 1–5）
- 气息：稳 / 紧 / 带笑气 / 带喘 / 带颤
- 尾音：收干净 / 拖一点 / 压住 / 上挑
- 情绪色彩：讥讽 / 温柔但不软 / 强装镇定 / 冷笑 / 压火

**C. VoiceID 规则**
正文中同一角色只能使用其 VoiceID，不得改写声线描述；只允许在【配音指令】里改变"语气特点"。每个分格（镜头）必须包含【配音指令】：角色｜VoiceID｜语气特点。

示例：广播剧主役声线｜青年男性，古风侠客音｜气息稳，语气自信满满

### 19. 重要说明

- 任何一个元素或者描述，在上一个分镜出现了，下一个分镜重复出现，必须全部写出来，**禁止使用"同上""同前"等省略字眼**
- 任何台词、内心 OS，**不允许改变原词**，如果超出时长，分到不同的画面中

### 20. 分镜片段组合方式（蒙太奇手法库）

1. **同一主体的景别转换**：主观镜头和客观镜头的过渡、放大角色情感
2. **对立主体的并列**：表示两边角色的平等对立
3. **并列 & 深进场景**：引导读者深入故事场景之中
4. **竖状分镜的上下运动**：表示镜头的上升或下降
5. **画面变焦**：合并焦距来节省格子
6. **视点切换**：切换到角色的第一人称视角增加代入感
7. **事物进入方向**：右边是已知或自己的方向，左边是未知或敌人来的方向（日式）
8. **连续的变化镜头**：强调时间流逝（思考）和停顿感
9. **仰视和俯视**：俯视表示客观环境、压抑、下风；仰视表示威压、开阔、上风
10. **单格内展现不同人体部位**：越接近头部越传达主观情感；全身表达肢体语言或气势
11. **摇动的格子**：表达不稳定性、强烈的心理波动或局势动荡，制造危机感
12. **同一空间内容分离的格子**：入幕或退幕；加大角色言行的时间间隔
13. **第一人称视角**：通过增加角色后脑勺大特写和虚化描写第一视角
14. **偷窥 / 跟踪视角**：营造监视效果；引出新角色；客观角度看清剧情；设置伏笔
15. **弱化主体剪影**：强调角色以外的部分；缓冲角色脸部审美疲劳；隐藏角色等
16. **颠倒镜头**：利用纵向表达横向景深等
17. **混剪 / 蒙太奇**：连接无法正常连接的镜头、更好传达情感或表现画面
18. **退幕镜头**：渐变缩小分格，或悬念式隐藏分格
19. **交叉剪切**：并列描写双线剧情达成紧张悬疑效果
20. **叠印联想**：在角色回忆时加上对应画面，引出伏笔、加强角色鲜活感
21. **重叠格子**：过渡；蒙太奇；先抑后扬
22. **人物爆格**：角色出场或增强冲击感 / 张力
23. **联想镜头**：不直接描写让读者自行联想剧情发展，增加故事余韵或规避审查
24. **同一格内多人说话**：节省时间、节省格子、缓冲阅读疲劳

### 21. 片段信息量

片段要足够细节，保证片段能把一个片段完整叙事串联起来，组建蒙太奇。而不是一个片段里塞太多信息，导致片段承载内容不足。**让片段信息量降低，片段数增多。**

### 22. 动作节奏

片段动态要符合动漫的情绪与情节节奏效果，该激烈的时候激烈，该转场的时候转场，该镜头运动的时候镜头运动，该大幅度动作的时候大幅度动作，该出现特效的时候给特效。

重点考虑情绪张力的动作表现，而不只是声音表现。

**片段动作简单化要求**：每个片段低于 3 个动作。示例——一个人起床：
| 片段1 闹铃响特写，| 片段2 翻身中景，| 片段3 睁眼近景，| 片段4 伸手关闹钟中景，| 片段5 转身躺下近景，| 片段6 猛然起身全景，| 片段7 揉头发睡眼惺忪中景，| 片段8 眼睛放大喊：完了！特写。

**必须规避敏感画面，禁止血腥、禁止限制级。符合上映标准。**

## 输出格式

请严格按照以下自定义格式输出所有分镜视频提示词 video_prompt。

```
有音效，无音乐，无字幕，运镜丝滑，人物动作流畅，中文对话
```
