# seedance-short-drama-storyboard
Seedance 短剧分镜视频提示词生成技能 - 把小说/文案转化为15秒分镜组video_prompt
优先把剧本转变为json格式，再生成分镜提示词。
建议使用chatgpt
在使用文本模型进行改写时，可以自己手动添加一些其它指令，比如：不要删减对话，不要改写内容，不要删减内容，13-15秒一个镜头，每个镜头3-4个分镜，保留每一句对话，每个镜头对话不超过60个字，如果超过，自动拆分为下一个镜头。要有明确人物位置关系的镜头。单人长台词禁止一镜到底，可切其他人反应镜头。双人长对话禁止一直使用正反打镜头，需穿插双人全景、侧景、中景等多种景别。固定镜头需要占比更多。人物情绪要刻划明显。遵循景别切换思路，按时长，运镜方式，场景人物动作描述，对白，音效，光影/情绪氛围的格式输出脚本。
这样可以达到更好的效果。
